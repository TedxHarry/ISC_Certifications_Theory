Download and extract the lab kit. Open the ISC_Certifications_Hands_On folder and read its README.md. It identifies the first lessons and their starting files.

Download the lab kit

The first setup uses three files in lab-data/baselineA: people.csv, report_accounts.csv and report_entitlements.csv. Keep the supplied files unchanged and follow the setup lesson to prepare private working copies for upload.

The kit also contains later data sets and a read-only evidence collector. You do not need to run a script for the first review.

## Evidence reasoning

The case matches identity, source, account, entitlement attribute and value, keeping names separate from internal record IDs and source-native identifiers. Exact available references are recorded rather than made up; a timestamp alone does not establish causal linkage. If UI/export references are insufficient, the learner records the precise gap for an authorized read-only API investigation before selecting an engine-specific contract.

Actual decision maker, current reviewer, sign-off actor, task recipient and file/target operator are separately inspected. No reassignment/admin-completion experiment is added to manufacture different people.

Original exports stay unchanged. A deliberately marked working index substitutes B Read evidence for A Read retention. Repair restores the genuine A reference or records the historical gap. A new present-state observation cannot retroactively establish past retention. This exercise changes no source/account/task/report data.

Later training reset is separately recorded. Historical absence, current state and later report generation are different claims. The package does not erase intermediate or inconvenient events. Missing/old records remain gaps without a guaranteed product retention period.

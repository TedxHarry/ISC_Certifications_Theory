## Beginner explanation and independence

Each lesson introduces the account, identity, source and assigned review needed for its own reasoning. New terms are tied to a visible problem: reassignment changes responsibility; a work redirect affects work as created; a recommendation helps investigation; a decision comment connects a choice to its facts; sign-off confirms an assigned review.

The six lessons need different teaching shapes.025 compares the unit being moved with the requested handover.026 follows before/during/after timing.027 builds a business justification before interpreting optional context.028 changes the item's origin and package scope.029 tests a shared reason against each selected item.030 follows saved and finalized states. The existing diagrams and tables explain these relationships rather than meet a quota.

Some supporting setup repeats because each learner file must work independently. The repetition identifies conditions that affect the outcome; no demonstrated omission or unnecessary new concept was found that warranted rewriting the learner text. This judgment does not replace participant feedback. In particular, actual novice reading difficulty and uncoached changed-case performance remain unmeasured.
